# OwnSpace

> Your space. Your people. Your progress.

**Status:** Under Development

## About

OwnSpace is a personal and collaborative digital workspace designed for engineering students to organize knowledge, manage projects, track learning progress, collaborate with friends, and balance productivity with meaningful breaks.

## Core Modules

- Personal and Shared Workspaces
- Knowledge Vault
- Smart Planner
- Learning Roadmaps
- Collaborative Project Management
- Developer Notebook
- Idea Lab
- Real-time Messaging
- Focus and Chill Rooms
- Productivity Analytics

## Technology Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB Atlas, Mongoose
- Real-time Communication: Socket.io
- Version Control: Git and GitHub

## Design Principles

- Privacy by default
- Minimal data redundancy
- Modular application architecture
- Storage-efficient database design
- Centralized design tokens
- Responsive light and dark themes
